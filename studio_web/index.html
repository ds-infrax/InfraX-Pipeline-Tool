Git 주소 또는 ZIP 파일 본문과 설명을 Marketplace 서버에 등록합니다.

            

          

          

            

              
              
            

            

              
              
            

            

              
              
            

            

              
              
            

            

              
              
            

            

              

                
                

                선택한 노드 타입을 등록 정보에 자동 입력합니다. 실제 소스는 같은 패키지의 Git 주소 또는 ZIP으로 등록하세요.
              

            

            

              
              
              쉼표로 구분합니다. 누락 노드가 이 목록과 일치하면 다운로드 항목을 바로 안내합니다.
            

          

          

            소스 선택
            
            
            
          

          

            
            
            Python 소스 전용 간편 게시입니다(.py/.pyi, README/LICENSE, requirements, pyproject만 포함). JSON/YAML/바이너리/리소스가 필요한 복합 노드와 모델은 검토한 Git 주소 또는 직접 만든 ZIP으로 등록하세요. 설치한 Marketplace 패키지와 로컬 경로는 전송하지 않습니다.
          

          

            
            
          

          

            
            
            ZIP 본문을 Marketplace 서버에 업로드합니다. 최대 100 MB.
